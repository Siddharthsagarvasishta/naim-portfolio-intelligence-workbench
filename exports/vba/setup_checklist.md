# VBA Setup Checklist

- [ ] Source reviewed by an authorized developer.
- [ ] Modules signed with an enterprise certificate.
- [ ] Workbook stored in a trusted, access-controlled location.
- [ ] `Naim_Config` contains only approved roots and no credentials.
- [ ] Named tables/ranges exist before module import.
- [ ] Formula-injection neutralization confirmed upstream.
- [ ] Refresh log and reconciliation visible.
- [ ] Macro-free Power Query alternative documented for recipients.
- [ ] Created PowerPoint is reviewed before saving or distribution.
