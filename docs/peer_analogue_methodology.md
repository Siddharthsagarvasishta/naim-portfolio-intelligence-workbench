# Peer Analogue Methodology

## Objective

Peers provide a defensible comparison population when the full portfolio is structurally inappropriate. They do not manufacture a control group or prove causality.

## Selection

1. Enforce exact eligibility constraints such as entity type, service class or product.
2. Match approved characteristics: mix, region, scale, tenure, risk, transactions, contract or criticality.
3. Standardize continuous features using the reference population.
4. Rank candidates by deterministic distance or nearest-neighbour similarity.
5. Apply calipers, minimum peer count and maximum dominance rules.

Optional propensity-style similarity scores are used only to assess comparability, not to imply treatment causality.

## Output

Expose selected peers, variables, weights, similarity, median, interquartile range, best/worst quartile, target percentile and distance from median. Confidence is downgraded when the pool is small, a feature is outside common support or one peer dominates.

## Stability

Peer versions are frozen for an approved report. On refresh, show membership changes and benchmark movement separately from target performance. Sensitivity compares alternative reasonable matching specifications.

## Restrictions

Do not choose peers after inspecting the desired outcome. Do not silently drop missing observations. Do not use external credit-rating symbols. Weak peers should yield “insufficient analogue quality,” not a precise rank.
